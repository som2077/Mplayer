# Expo + NativeWind Starter

This folder contains a minimal Expo app scaffolded with NativeWind for Tailwind-like styling in React Native.

What you get:
- Expo app with a TypeScript entry (App.tsx)
- NativeWind configured via Tailwind provider and Babel plugin
- Tailwind config and PostCSS setup

Getting started:
- Tech: Expo (managed), React Native, NativeWind (Tailwind for RN)
- Run from this folder:
  1. npm install (or yarn)
  2. npm run start

Notes:
- This is a starter scaffold. Replace App.tsx with your app code and expand the Tailwind setup as needed.
