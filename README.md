# Expo Music Player (Milestone 1 Skeleton)

This repository contains a skeleton for a mobile music player built with React Native and Expo. It focuses on local-file playback, playlist persistence, and a minimal UI to kick off Milestone 1.

- Local-only: Users import audio via Expo Document Picker
- Playback: Play/Pause, Seek, Next/Prev, Volume (wired in core engine)
- Playlists: Persisted with AsyncStorage
- Theme: Dark-first with an optional light mode (not toggled yet in UI)

Usage
- Install dependencies: npm install
- Start: npm run start

Notes
- This is a plan-to-build skeleton. The core playback engine and UI are scaffolded to accelerate Milestone 1 delivery.
